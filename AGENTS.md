# Portfolio website
This is the source code for my personal website/portfolio. Created with Astro + Tailwind.

## Important commands:

```bash
# Build the app
npm run build
# Preview server
npm run preview

# Code checks
npm run typecheck
npm run lint

# Apply automatic linter fixes
npm run lint:fix
```

## General coding guidelines
Always run the linter and typecheck after your changes. Your work is not done until both land green!
